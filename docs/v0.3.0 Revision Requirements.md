# HavenGM v0.3.0 Revision Requirements

Source: full in-game user test pass on 2026-07-25.

## Shared UI

- Replace the unsupported Unicode teleport star with a client-safe icon.
- Hover colors must always restore the correct persistent button/tab state.
- Lookup modals should be visually attached to the HavenGM frame.
- Search result selection should fill both the ID and matching name fields.
- Search/name inputs should have a red clear button.
- Use Ctrl + Right-click, not Shift + Right-click, for ID capture.
- Log every implemented change and keep the Vault current.

## General

- Verify or remove Revive.
- Explain Save in its tooltip.
- Replace free speed stepping with presets: 1, 2, 3, 5, 7, 10, 15, 20.
- Keep a non-editable current requested speed display and Reset Speed.
- Treat -80% HP as unreliable and replace/remove it unless it can be safe.
- Split the page into Combat and Utilities.

## Character

- Remove Current level.
- Verify or remove Max Skills.
- Keep Customize and Rename with clearer explanations.
- Item capture uses Ctrl + Right-click and clears stale search text.
- Align Item Add/Remove like the Spell actions.
- Make spell target semantics explicit: Learn/Unlearn target or self fallback,
  Cast Self and Cast Target.
- Separate Morph into its own section and provide discoverable presets or
  searchable data only when the server/client can support it.

## Quests

- Remove Use Log ID.
- Remove unsupported Reward and Active Quests commands.
- Explain that Complete is server-limited and may not finish scripted goals.
- Provide a replay/reset workflow only if HavenCore source exposes a safe,
  verified command that clears rewarded/completed state.
- Provide a reliable button to load a visible quest's ID into HavenGM.

## Teleport

- Keep the categorized dropdown workflow.
- Replace the unsupported star glyph with client-safe favorite art.
- Keep visible favorite buttons.

## Lookup

- Remove Use First ID and Primary Action.
- Keep Go To Workflow with clearer wording/tooltip.
- Remove Raw Server Output.
- Use only the result modal, anchored to HavenGM.

## Creator

- Rename spawn actions to TEMP and PERM.
- Remove TGT INFO from the primary workflow.
- Rename GameObject spawn actions to TEMP and PERM.
- Remove unreliable/confusing GameObject MOVE, DELETE, USE, TURN/APPLY,
  NEAR 25 and INFO ID from the primary Creator workflow; advanced inspection
  belongs under Debug.
- Keep emote presets and speech.
- Review/remove non-working Sleep preset.
- Treat Sound ID and raw Animation ID as advanced debug features rather than
  primary Creator controls.

## Debug

- Remove unsupported Active Quests.
- Remove Client-side Snapshot controls.
- Move captured raw server output here from Lookup.
- Keep advanced inspection and proximity commands here.
- Display client position/map continuously as read-only debug information.
- Make captured results selectable/copyable inside the addon.

## Settings and quest integration

- Quest ID display must work in the BFA map and quest log without overlapping.
- Add a direct capture action for the selected/visible quest where modified
  clicks are consumed by Blizzard UI.
- Update setting text to Ctrl + Right-click.

- Make Speed editable from 1-20 while retaining minus/plus, Reset Speed and

- Remove the Morph section.
- Make visible quest IDs directly clickable and fill both Quest ID and name.
- Fix Load Selected Quest when the BFA map does not expose a selected ID.
- Remove Blizzard-blocked self-target calls from Quest Remove/Replay.
- Fix Lookup dropdown/input overlap and Search Modal footer overlap.
