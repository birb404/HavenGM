# HavenGM v0.3.0-beta Change Log

## v0.3.1 correction

- Removed Freeze from Creator. HavenCore `.freeze` accepts player characters,
  not NPC targets.
- Friendly/Hostile is disabled and labelled Possessed while HavenGM possession
  is active, preventing the addon from displaying a misleading faction state.

## v0.3.2 follower layout

- Anchored the first follower portrait beside the window's top-right close
  control and stacked every additional portrait directly below it.
- Increased follower portraits from 38 to 48 pixels (approximately 25%).
- Limited active and restored follower portraits to eight.
- Prevented `.npc follow` from being sent when the follower list is already
  full.

## v0.3.3 unconditional follower dismissal

- Right-click always removes a follower portrait and its saved local record,
  even when the NPC is dead, despawned or can no longer be targeted.
- `.npc follow stop` is still sent when the exact follower can be targeted.

## v0.3.4 community link and credit

- Added a WoW Haven Discord button to the Settings tab.
- Clicking the button opens a selectable invite URL because WoW addons cannot
  launch external browser links directly.
- Added `Created by birb@` to the Settings tab.
- Replaced the incompatible paletted BLP2 icon with an uncompressed 32-bit TGA
  for reliable rendering in the BFA 8.3.7 client.

## v0.3.5 usability and workflow pass

- Runtime cheat, god, cast, cooldown, power and fly indicators now start OFF
  whenever the addon loads, without issuing server commands.
- Added a non-lethal Foam Hit that caps requested damage at current health
  minus one.
- Rebuilt speed controls around an editable 1-20 field, immediate minus/plus
  steps, eight presets and Reset Speed.
- Removed the Morph interface.
- Added secure self-target buttons for Quest Remove and Reset for Replay,
  avoiding blocked `TargetUnit` calls.
- Quest list ID badges are clickable and load both quest ID and name. Load
  Selected Quest falls back to the last clicked quest.
- Fixed Lookup dropdown/search spacing and moved Search Modal Next away from
  the result counter.
- Added a clear button to Creator speech.
- Expanded Debug server output, moved actions into a right-hand vertical
  column, and uses the last parsed server GPS Z when the client returns zero.
- Rebuilt Settings footer into separate Community and About panels and changed
  the credit to `Addon created by Birb@`.
- Removed overlapping tutorial/telemetry copy and normalized touched control
  spacing.

## v0.3.6 visual cleanup

- Removed Z from Live Position because this BFA client does not provide it
  reliably.
- Added a dedicated gutter between the Debug output scrollbar and its vertical
  action buttons.
- Removed the wrapping item-capture help text that overlapped the Spells
  section.

## Shared UI

- Added persistent resting colors so hover no longer leaves tabs or toggles
  highlighted.
- Anchored the lookup modal to the HavenGM window.
- Lookup selections now fill both destination ID and matching search name.
- Added red clear buttons beside search fields.
- Changed supported modified-click ID capture to Ctrl + Right-click.
- Increased the main window height to provide clean spacing.
- Replaced quest-title suffixes with separate right-aligned ID badges so the
  objective tracker is not widened or overlapped.

## General

- Split Combat and Utilities.
- Replaced unreliable percentage damage with Kill Target only.
- Changed Revive and Repair to explicit self actions by character name.
- Documented Save Character.
- Replaced editable speed stepping with x1, x2, x3, x5, x7, x10, x15 and x20
  presets plus a read-only requested-speed display and Reset Speed.

## Character

- Removed Current and Max Skills.
- Kept level, talents, customization, rename, race, faction and languages.
- Split Items, Spells and Morph into aligned sections.
- Clarified Learn self/target and Unlearn target behavior.
- Clarified that Morph requires a Display ID discoverable through NPC Info.

## Quests

- Replaced Use Log ID with Load Selected Quest.
- Removed Reward and Active Quests.
- Added source-verified Reset for Replay using quest remove followed by add.
- Documented ForceCompleteQuest limitations for scripted content.

## Teleport

- Replaced unsupported Unicode star text with the built-in ReputationStar
  texture.

## Lookup

- Removed Use First ID, Primary Action and Raw Server Output.
- Kept a clearly labelled Open Matching Tool action.
- Lookup now uses only the attached result modal.

## Creator

- Renamed spawn actions to Temp and Perm.
- Removed target info and unreliable primary GameObject controls.
- Retained NPC controls, GameObject spawning, emote presets and speech.
- Moved raw Sound and Animation IDs to Debug.
- Removed the non-working Sleep emote preset.

## Debug

- Removed Active Quests and Client-side Snapshot actions.
- Added continuously updated read-only position/map information.
- Added selectable captured server output inside Debug.
- Added First ID extraction into a selected, copyable field.
- Captured inspection output is suppressed from the normal chat frame.
