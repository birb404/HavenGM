# HavenGM v0.1.x Test Checklist

The addon is installed in the full BFA 8.3.7 client. Complete this checklist
before calling v0.1.0 stable.

## Load and layout

- [ ] `/reload` completes without a Lua error.
- [ ] The frame opens with `/hgm`.
- [ ] All eight tabs fit and switch correctly.
- [ ] The last selected tab survives `/reload`.
- [ ] Window position survives `/reload`.

## Runtime state

- [ ] CHEATS toggles GM, God, Cast, CD and Power together.
- [ ] CHEATS does not change Fly.
- [ ] Individual cheat buttons update the CHEATS header consistently.
- [ ] Fly operates independently.
- [ ] A fresh client login displays all runtime toggles OFF without sending
      commands.
- [ ] `/reload` preserves local display state.

## Preserved tools

- [ ] Kill target and -80% HP work.
- [ ] Speed plus/minus applies immediately.
- [ ] Reset Speed applies speed 1.
- [ ] Exact level works in both directions.
- [ ] Item add/remove works.
- [ ] Spell learn/unlearn and cast actions work.
- [ ] Quest add/complete/remove/go-to work.
- [ ] Teleport and Return to Last Location work.
- [ ] Shift-right-click captures item, quest and spell links.

## Lookup and debug

- [ ] Item, spell, quest, creature, object and teleport searches run.
- [ ] Raw server output appears in Lookup.
- [ ] GPS, NPC Info, Object Info and Active Quests feed the output panel.

## Regression notes

Record every error with its full Lua stack and the exact button/tab that caused
it. Do not mask errors by disabling Lua error display.
